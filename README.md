Neon Coast Cover Studio — turn any photo and a caption into GTA-style poster art. A five-panel hero layout (or a 2×2 grid, or one full-bleed photo) with a Vice City neon-sunset grade, halftone and grain, big Anton title lettering with a neon Pacifico subtitle, per-panel crop and position, and one-click export in all three post sizes — 1080×1350 portrait, 1080×1080 square and 1920×1080 landscape. It runs entirely offline in a desktop browser: photos are read on your machine and never uploaded. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080, load a photo (or try a bundled sample), pick a layout and grade, type a caption, and hit **Export all 3 sizes as PNG**.
